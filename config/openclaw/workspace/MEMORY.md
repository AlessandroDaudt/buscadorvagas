# Memoria duravel

O perfil explicito e o curriculo aprovado sao as fontes principais. Vagas salvas/descartadas e empresas aprovadas/rejeitadas sao sinais que devem ser combinados com contexto, data e quantidade de exemplos.

Nunca memorize dados pessoais. Armazene somente padroes profissionais generalizados, hipoteses de pesquisa, URLs publicas ja avaliadas e resultados dos lotes.
